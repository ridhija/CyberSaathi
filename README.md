# CyberSaathi — Multilingual Cybersecurity Awareness

CyberSaathi is a beginner-friendly, responsive educational website that helps people recognise common online scams and build safer digital habits.

## Features
- Language selector: English, Hindi, Punjabi, Bengali, Marathi, Tamil, Telugu, Gujarati
- Simple lessons on suspicious messages, passwords, and device safety
- Interactive fictional scam-awareness quiz with feedback
- Personal safety checklist (runs only in the browser)
- Responsive layout for phones, tablets, and desktops
- No login, analytics, backend, or personal-data collection

## Run locally
Open `index.html` in a modern web browser. No build step or dependencies are required.

## Deploy with Vercel
1. Sign in to Vercel with GitHub at https://vercel.com/
2. Choose **Add New → Project** and import `ridhija/CyberSaathi`.
3. Keep the default settings; this is a static HTML site and needs no build command.
4. Click **Deploy**. After deployment, Vercel will provide a public URL.

## Educational and privacy note
All examples are fictional and for awareness training only. The quiz never asks for credentials, OTPs, payment details, or personal information. This project does not collect or transmit checklist responses. Translations should be reviewed by fluent speakers before formal/public training. Review the content periodically as scam tactics change.
